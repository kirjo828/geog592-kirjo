I chose spotted lanternfly and tree-of-heaven because
tree-of-heaven is a preferred host of the spotted lanternfly.
I wanted to examine where observations of these species
overlap across the Mid-Atlantic.

The four choropleth maps demonstrate how classification
schemes can change the appearance of the same data.
Continuous colors show more detailed differences between
counties. Equal intervals are easy to understand, but can
group most counties into one category if the data are uneven.
Quantiles distribute counties more evenly, although similar
values can fall into different categories. Natural breaks
group similar values together, but the boundaries depend
on the dataset.

The bivariate map is useful for identifying counties with observations of both species. One limitation is that GBIF
observation records depend on where people report sightings.
Fewer records do not necessarily mean a species is less common.
